# She Can Foundation - Contact Form

A full-stack contact form application I built for She Can Foundation. It has Responsive frontend, Node.js backend, Form Validation, Secure API Integration, and Google Sheets as Database.

## 🎯 What I Built

A professional contact form with:
- Split-screen responsive design with navy & orange brand colors
- Real-time validation (frontend & backend)
- Glass-morphism UI with smooth animations
- Automatic submission storage in Google Sheets

---

## 🛠 Tech Stack

**Frontend:** Vanilla JS, HTML5, CSS3 (no frameworks)  
**Backend:** Node.js + Express with express-validator  
**Database:** Google Sheets API (service account authentication)  
**Deployment:** Vercel (frontend) + Render (backend) with auto-deploys from GitHub  

---

## 💻 How It Works

1. User fills form on frontend
2. Frontend validates input
3. Data sent to backend API
4. Backend validates again (security layer)
5. Google Sheets API stores the submission
6. User sees success notification

**Form Fields:** Name (min 2 chars), Email, Message (min 10 chars)

---

## 🔐 Security

- Client-side validation (UX)
- Server-side validation (security)
- CORS configured for production only
- Service account authentication (Google's standard)
- Environment variables for sensitive credentials

---

## 📧 Contact Form Features

Users can:
- Fill out their name, email, and message
- See validation errors in real-time (helpful feedback)
- Submit and get instant confirmation
- Have their data automatically saved to the spreadsheet
- Provides a great user experience while keeping data secure
